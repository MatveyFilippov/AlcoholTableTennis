# Дизайн ATT

Светлый русский интерфейс с тёплым фоном, тёмным читаемым текстом, зелёным акцентом теннисного стола и небольшими оранжевыми деталями. Сохраняйте простую типографику, тонкие разделители, выраженный фокус и табличные цифры. Теннисные детали дополняют навигацию и счёт. Формы и графики используют один визуальный язык.

- **Вечером.** Вход через «Матч», «Игроки» и «Алкоголь». Для счётчика два крупных поля начисления очков, видимые имена, цель, счёт, отмена и отдельное подтверждение результата. Основные элементы управления не ниже 44 px.
- **Утром.** «Итоги вечера» выводят лидера и недавние результаты. Рядом виден рейтинг, ниже — выбор игроков на графике Elo. Факты появляются только при достаточных однозначных данных.
- **Детали.** Аналитика содержит сравнение начала и конца, личные встречи и связь результатов с записанным этанолом. Точки графика имеют подписи и дублируются доступным списком. Мобильные строки таблиц допускают перенос длинных псевдонимов.
- **Состояния.** Показывайте пустой вечер, неизвестную самооценку, маленькую выборку, устаревший снимок, ошибку сети и восстановление черновика. Уважайте `prefers-reduced-motion`. Интерфейс проверяется на 320, 390 и 1440 px с тестовыми данными.
