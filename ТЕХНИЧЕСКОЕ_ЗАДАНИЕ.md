# Техническое задание · Alcohol Table Tennis

ATT — сайт одного непрерывного вечера настольного тенниса с друзьями. По ходу вечера участники записывают результаты и напитки. После вечера доступны рейтинг, личные встречи и сравнение результативности. У вечера нет автоматического сброса.

Посетитель добавляет игроков, напитки и матчи. Администратор исправляет, мягко удаляет и восстанавливает записи с аудитом. Матч — одна игра до 11 или 21 с перевесом от двух очков. Для обоих игроков фиксируется отдельная самооценка 0–10 или «Неизвестно». Счётчик на одном устройстве сохраняет черновик, поддерживает отмену и публикует итог только после подтверждения.

Единый Elo начинается с 1000, K=32. Порядок игры для Elo — серверный номер публикации. Накопленный этанол считается на начало игры, по активным напиткам до номера снимка. Исправления пересчитывают зависимую историю. «Начало vs Конец» сравнивает средний фактический исход минус ожидаемая вероятность победы в двух равных половинах собственных матчей, минимум четыре игры. Средний матч нечётной выборки исключается. Алкогольная аналитика описывает наблюдения без медицинской или причинной интерпретации.

Светлая тема, русский интерфейс, адаптация от 320 px. Стек: React/TypeScript/Vite, FastAPI/SQLAlchemy/Alembic/PostgreSQL, Caddy и Docker Compose. PR в dev и main проверяют четыре CI jobs. Публикация стабильного GitHub Release текущего main запускает production workflow после успешных проверок и публикации образов.
